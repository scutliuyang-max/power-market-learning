# 电力市场学堂

独立静态网页版：递进课程、交互算例与省级规则资料库。部署后访问者不需要 ChatGPT 或 GitHub 账户。

## 功能

- 6 模块、30 节学习课程，包含中文讲义、目标、术语、完整示例、独立练习、常见误区与来源。
- 15 个国家、16 个国家或区域市场案例，可按统一维度并排比较并导出笔记。
- 15 项教材、大学公开课程和官方教程，注明语言、开放程度、原始来源及阅读顺序。
- 4 个算例：电量与电费、单节点出清、合同差价、日前与实时两结算。
- 4 组交互教学动画，嵌入 5 节课程，可播放、暂停和逐步查看。
- 18 条带官方来源及版本信息的规则资料入口，按地区、主题和关键词筛选。
- 适配电脑和手机浏览器；学习进度仅保存在本机浏览器。
- 光储盈利规划：山东、山西、广东、浙江、江苏、蒙西规则提示，比较不建设、仅光伏、仅储能与光储组合。

## 光储盈利规划

入口：`#planner`。输入 24 小时负荷、光伏归一化出力、可避免购电单价、光伏上网价、设备配置与全周期成本，比较项目整体的税前无融资现金流、NPV、IRR、首次静态回收期和储能相对仅光伏的增量价值。支持浏览器本机参数保存及 JSON 报告导出。

默认参数均为演示假设，不是某省官方电价。地区选择只切换规则依据与条件核对，机制资格确认会随地区变更重置。收益规则与参数仍需根据有效文件、项目计量关系及零售合同确认。

调度引擎使用每日循环 SOC、60 个可用容量步长，在 24 个 1 小时时段内最小化购电费用减余电收入。充放电互斥，功率/容量受限，效率按充放两侧平方根分配。光伏优先直接自用，储能只向负荷放电；允许有权弃光的项目减少负价上网。储能预留比例同时减少套利功率与容量。离散化、完整曲线预知、未约束循环寿命、未约束变压器购网功率均会影响结果。

年收益由同一个典型日外推到指定天数，其他天数不计能源收益；每年重算光伏衰减、储能容量衰减和更换。机制差价仅按光伏实际出口量、确认比例、参考价及剩余年限估算，未复刻各省逐月清算。需求响应与基本电费节省默认不计，必须有已核实净收益；需求响应需预留资源。不得将独立储能容量电价、绿证、辅助服务或补贴直接叠加。未实现独立储能生产交易、绿电直连合规检查、EMC双方现金流、融资与税务、建设期、退役和残值。

计算测试：`node tests/planner.test.cjs`，覆盖能量守恒、SOC闭环、功率约束、损耗、收益去重、资格与到期、更换、NPV/IRR。

## 本地运行

需要 Node.js，在仓库根目录运行：

```sh
node server.mjs
```

打开 http://localhost:4173 。无需安装依赖或配置 API 密钥。

## GitHub Pages 发布

1. 在 GitHub 创建 `power-market-learning` 仓库，使用 `main` 分支。使用免费账户发布时建议创建 Public 仓库（源代码将公开）。
2. 上传此目录全部文件，包括 `.github/workflows/pages.yml`，不要上传 ZIP 文件本身。
3. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
4. 在 **Actions** 中运行 **Deploy learning app to GitHub Pages**，或再次推送到 `main`。
5. 以 Actions 部署结果中的网址为准。通常为 `https://<用户名>.github.io/power-market-learning/`。

每次更新 `main` 后自动发布 `dist`。页面使用相对资源路径和 hash 路由，支持 GitHub Pages 仓库子路径。

网站公开访问，未实现独立账号登录与跨设备同步。账号、后台、资料上传和全文检索需要后续增加。

## 站内文件资料库

`dist/documents/` 保存官方 PDF 原件与单独排版的官方网页正文留存，读者可在规则库直接阅读和下载，无需 ChatGPT 账户。PDF 不改动原始字节；HTML 留存包含来源、类型与收录日期，并禁用脚本。原始附件链接、文件大小、页数和 SHA-256 保存在 `dist/documents/manifest.json`，`dist/document-library.js` 将文件关联到规则条目。

本批收录日期为 2026-10-04：18 条资料中 16 条已保存文件（5 份 PDF、11 份网页正文）。江苏两条因官方下载返回 403，明确保留为待下载条目。浙江条目为修订动态，山西 V15.0 为历史版本，各地尚未全部覆盖，也未自动确认文件最新有效性。

更新文件时须核对官方正文与附件、保留历史版本、更新 manifest 及关联数据，并运行 `node tests/library.test.cjs`。该检查验证文件存在、原始字节大小和 SHA-256，避免上传遗漏或文件损坏。

## 手机 PDF 阅读

PDF 站内阅读默认使用 Mozilla PDF.js 兼容版，支持逐页、页码跳转、适应宽度和缩放；仅渲染当前页，画布不超过 400 万像素。同时提供逐页自动提取的文字阅读版，排版或扫描页可能提取不完整，原件图文优先。PDF 原件和已有 HTML 正文均保留。

首次本地运行前执行 `python scripts/prepare-pdfjs.py` 下载带校验值的官方 PDF.js 发行包到 `dist/vendor/pdfjs/`，再运行 `node server.mjs`。GitHub Actions 在部署时执行同一构建，浏览器从本站加载阅读器、worker、字体和字符映射，不依赖第三方 CDN。

## 学习工作台与零基础教学

2026-10-07 更新：灰白侧栏与留白布局、明暗主题本机保存、手机折叠菜单。首页推荐下一课，学习路线先介绍单位、主体与时间线，再学习出清、实际计算与合同风险。原有课程 ID 保留，新增 ID 12 的光储收益入门课，区别运行毛收益和项目盈利。

每课采用目标、讲解与示例、独立练习三步；数值练习与概念自测按知识点安排。术语可展开解释，课程显示前置知识；答对后标记完成、继续下一课。实验室提示先预测、再只改变一个参数并解释结果。学习进度不等于正式能力认证。

`node tests/learning.test.cjs` 验证课程 ID、前置关系、术语和练习计算；原资料库与盈利模型测试继续执行。教学设计参考： https://ies.ed.gov/ncee/wwc/PracticeGuide/1 （示例与练习交替、用测验促进回忆）。

## 交互教学动画

电量累积、机组出清、日前与实时偏差结算、储能损耗与运行毛收益共 4 组动画，在相关课程的“讲解与示例”中打开。先预测，再播放或逐步查看数值，最后完成独立练习；观看动画不会直接标记学完。出清需求、正负偏差、储能效率及替代购电单价可切换对比。

默认不自动播放，支持暂停、重播、上一步、下一步和步骤滑块；关闭课程、切换教学步骤或隐藏网页时停止播放。浏览器启用减少动态效果后使用静态步骤。手机采用单独的紧凑图示布局，支持明暗主题。

动画由 `dist/lesson-animations.js` 与 `dist/lesson-animations.css` 中的 SVG、CSS 和 JavaScript 绘制，不使用视频、外部 CDN 或 API。动画代码、课程内容及 `dist/documents/` 中的学习资料继续保存在此 GitHub 仓库，通过 GitHub Pages 同站发布。演示数字不代表省级官方价格；模型边界在图示下方标明。

`node tests/animations.test.cjs` 验证能量守恒、出清价格边界、供给不足、正负偏差与储能毛收益计算。

## 深入课程、教材与国际市场

入口 `#courses` 采用六模块：基础与数据、价格与约束、合同与结算、运行与政策、项目与灵活性、国际比较与综合设计。新增成本报价、福利、启停与爬坡、加权价格、双节点网络、备用机会成本、资源充裕性、负价、PPA/CfD、零售账单、市场力、SOC、需求响应基线和NPV课程，原13课补充深入段落。每课可下载本站讲义，`#resources` 可导出全套中文讲义、练习参考答案与来源。

`#resources` 包含 MIT OCW、NPTEL、PJM、FERC、AEMO、Nord Pool 和教材出版社/作者资源，共15项及三条阅读路线。历史公开课程用来学习机制，不作为当前政策依据；教材书目不等于开放全文。本站不保存未获再分发许可的第三方教材全文，中文教学讲义、原创算例和阅读指南作为仓库内静态资源集成。

`#international` 首批覆盖中国、美国（PJM和ERCOT分别建档）、英国（大不列颠）、德国（结合欧盟框架）、法国、日本、澳大利亚（NEM）、新加坡、挪威、瑞典、印度、智利、韩国、巴西和南非。按管理运营、交易时序、定价、平衡、充裕性、灵活资源六个维度对照，各段来源编号关联官方机构，并附自设数值案例。来源访问日期为2026-10-07，文档日期与改革实施状态分别标明；不是所有国家、地区的完整现行法规合集。

新增国家/区域时需确认地域边界、产品单位、交易与结算间隔、政策日期和来源支持；更新改革时区分提出、决定、投运和交付期。新增课程时保留旧ID、检查先修顺序，手算题需明确模型边界与单位。所有内容继续通过此 GitHub 仓库及 GitHub Pages 同站发布，无需读者注册账户。

`node tests/academy.test.cjs` 验证30个稳定课程ID、六模块先修顺序、术语及来源、资源关联、15国16案例范围与段落引用。
